## 1. Контекст

Рабочий стол уже цельный: бар Wayle, три виджета Quickshell на нижнем слое, док, эквалайзер,
карточка плеера, обои hyprpaper, локскрин hyprlock. Палитра — Catppuccin Mocha.

Но «постовости» не хватает по четырём причинам, и все четыре проверены фактами, а не на глаз:

1. **Стекло не читается.** Блюр зажат до `size 4 / passes 1 / vibrancy 0`, а низ обоев
   (y ≈ 880–1080) — ровная заливка, поэтому размывать нечего. Виджеты выглядят
   полупрозрачными рамками на пустоте.
2. **Палитра не везде.** `starship.toml` и `fastfetch/config.jsonc` раскрашены в Tokyo Night;
   `gsettings` отдаёт GTK-тему `Tokyonight-Dark`, иконки и курсор `Adwaita`, хотя в
   `~/.config/gtk-3.0/settings.ini` уже прописан Catppuccin, в `~/.themes` лежит готовая
   тема `catppuccin-mocha-mauve-standard+default`, а в `~/.local/share/icons` — курсор
   `catppuccin-mocha-mauve-cursors`.
3. **Три кисти на одну задачу.** Уведомления рисует mako, OSD — swayosd, бар — Wayle.
   Три набора радиусов, теней, палитр и поведения.
4. **Детали не вылизаны.** Локскрин показывает другую картинку, чем стол; карточка плеера
   появляется рывком; у дока нет жизни под курсором; цвета hyprland.lua, Wayle и Quickshell
   дублируются в трёх местах и могут разъехаться.

Цель — система, которую не стыдно выложить: одна палитра, живое стекло, аккуратная сцена.

## 2. Цели и критерии успеха

| Цель | Критерий приёмки |
|---|---|
| Стекло работает | Блюр виден на баре, виджетах, дропдаунах, локскрине; FPS под анимацией под блюром не ниже 55 на 1920×1080 (замер, §12.1) |
| Обои дают стеклу опору | На обоях есть структура по всей площади; контраст структуры на нижней полосе (y 880–1080) не ниже, чем в центре; бандинга нет |
| Одна палитра | Все перечисленные в §7 файлы получаются из `theme/palette.toml`; `theme/check.sh` не находит посторонних цветов |
| Ни одного чужого стиля | Tokyo Night не встречается ни в одном конфиге, которым управляет рис |
| Одна кисть для обвязки | Уведомления и OSD рисует Wayle в палитре и стекле бара; mako и swayosd не в автозапуске |
| Сцена собрана | Низ виджетов на одной линии, отступы 16 px, стекло у всех трёх из общих токенов |
| Композитор в той же палитре | Цвета границ и теней в `hyprland.lua` приходят из общей палитры; `hyprctl configerrors` пуст |
| Обратимость | Каждая правка — бэкап + откат; `uninstall.sh` возвращает состояние до риса |
| Воспроизводимость | `install.sh` на чистой системе даёт тот же вид: обои, палитра, темы, курсор, обвязка |

## 3. Не-цели (YAGNI)

Явно **вне области работ**: тема загрузки (GRUB/plymouth), экран входа в систему,
многомониторные раскладки, палитра, вычисляемая из обоев (`matugen`/`wallust`/`pywal`
остаются установленными, но не используются — палитра фиксированная, это осознанный выбор
в пользу «Catppuccin Mocha до блеска»), новые виджеты рабочего стола (часы и системный
монитор отклонены ранее), погода, заметки, смена бара Wayle на самописный, рефакторинг
функциональности виджетов, `waybar` (уже выведен).

## 4. Решения и обоснование

| # | Решение | Почему |
|---|---|---|
| D1 | Обои генерируются слоями (база → пятна → аврора → структура → зерно → виньетка), детерминированно по seed | Только детали под стеклом делают блюр видимым. Seed даёт воспроизводимость: один и тот же вариант всегда одинаков |
| D2 | Значения блюра выбираются замером FPS с оверлеем Hyprland, а не на глаз | На Intel UHD 620 блюр — единственная реальная нагрузка композитора; «на глаз» тут значит «наугад» |
| D3 | Палитра — один файл `theme/palette.toml` + рендерер, палитра **не** выводится из обоев | Выбран вариант «Catppuccin до блеска». Автовывод дал бы цвета, уходящие от палитры при каждой смене картинки |
| D4 | Приложения приводятся в палитру: GTK, иконки, курсор, шрифты, gsettings/портал | Сейчас gsettings расходится с `settings.ini` — часть приложений (через портал и Xwayland) живёт в чужой теме |
| D5 | Уведомления и OSD — внутрь Wayle; mako и swayosd вне автозапуска | Одна кисть: та же палитра, скругление, стекло, анимация. Минус два демона. Пакеты и конфиги остаются → откат строкой |
| D6 | Блюр за баром **включается**, непрозрачность бара опускается до ~78 | Отменяет прежнее решение «blur = false для wayle-bar». Раньше размывать было нечего (плоские обои). Проверяется скриншотом; откат — одна строка `hl.layer_rule` |
| D7 | Медиа-клавиши переводятся с `swayosd-client`/`playerctl` на `wayle audio` / `wayle media` | Один источник правды о громкости и активном плеере; залипший Telegram закрывается `players-ignored` внутри Wayle |
| D8 | Композиция виджетов выравнивается одной линией низа и общими токенами; новых виджетов нет | Раскладка уже принята пользователем и геометрически почти верна (818/1715/16 по X). Работа — в выравнивании и в «жизни», а не в пересборке |
| D9 | Смена обоев — скрипт + хоткей; локскрин берёт вариант той же картинки | Сейчас локскрин и стол показывают разные картинки — это ломает единство кадра |
| D10 | `hyprland.lua` получает цветовой блок из общей палитры (маркеры + подстановка) | Иначе цвета границ, теней и Wayle/Quickshell живут в трёх местах и разъезжаются. Проверяется `configerrors` и скриншотом |
| D11 | Источник правды — репозиторий `~/rice`, `install.sh` раскладывает всё с нуля | «Пост» должен воспроизводиться, а не жить только на этой машине |

## 5. Архитектура

Слоёв рисования по-прежнему три, но у каждого ровно одна задача:

```
┌─ Hyprland 0.56.2 ────────────────────────────────────────────────┐
│  обои hyprpaper ← gen-wallpaper.py (слои, seed)                  │
│  стекло: blur/vibrancy/тени ← замер FPS                          │
│  цвета границ и теней ← theme/palette.toml (блок с маркерами)    │
└──────────────────────────────────────────────────────────────────┘
┌─ Wayle 0.7.0 — вся обвязка ──────────────────────────────────────┐
│  бар, дропдауны, уведомления (вместо mako), OSD (вместо swayosd) │
│  громкость/яркость/медиа по командам wayle audio|media           │
└──────────────────────────────────────────────────────────────────┘
┌─ Quickshell 0.3.2 — только стол ─────────────────────────────────┐
│  карточка плеера, док, эквалайзер (namespace qs-widgets)         │
└──────────────────────────────────────────────────────────────────┘
┌─ theme/ — один источник цвета ───────────────────────────────────┐
│  palette.toml → render.py → kitty, wofi, btop, cava, starship,   │
│  fastfetch, GTK settings.ini, Wayle [styling.palette],           │
│  Theme.qml, блок цветов hyprland.lua, gsettings                  │
└──────────────────────────────────────────────────────────────────┘
```

Поток данных односторонний: правится `palette.toml`, запускается рендерер, конфиги
перечитываются (`hyprctl reload`, `wayle panel restart`, перезапуск службы виджетов).
Обратной записи из конфигов в палитру нет — иначе источник перестаёт быть источником.

## 6. Обои и стекло

### 6.1 Генератор

`hypr/scripts/gen-wallpaper.py` переписывается из «пятно + зерно» в слоистый генератор:

| Слой | Что даёт | Параметры |
|---|---|---|
| 1. База | градиент `crust → base` по диагонали, низ темнее | низ на 25–35 % темнее верха |
| 2. Пятна | 5–7 мягких цветовых пятен: mauve, blue, pink, teal (по seed) | радиус 300–700 px, аддитивное смешивание с затуханием |
| 3. Аврора | лента поперёк кадра поверх пятен | средняя деталь: именно её «дышит» блюр |
| 4. Структура | многооктавный шум, ±3–4 % яркости, на всю площадь | высокочастотная деталь для стекла |
| 5. Зерно | монохромный шум ±2 % | убирает бандинг на 8 битах |
| 6. Виньетка | затемнение краёв, нижняя полоса — не пустая | фон для виджетов и бара |

CLI: `--variant mauve|blue|teal|rose|mix`, `--seed N`, `--size WxH`, `--out PATH`, `--lock`.
Основной вариант — `mix`, для локскрина — тёмный вариант той же картинки (`--lock`),
чтобы кадр запирания продолжал кадр стола.

### 6.2 Стекло

Стартовый набор (далее уточняется замером):

```lua
blur = {
    enabled  = true,
    size     = 6,
    passes   = 2,
    noise    = 0.015,   -- мягкая плёнка поверх размытия
    contrast = 1.05,
    brightness = 0.92,
    vibrancy = 0.12,
    vibrancy_darkness = 0.03,
    popups   = true,    -- дропдауны Wayle
    special  = false,
    new_optimizations = true,
}
```

Одновременно: `inactive_opacity` 0.94 (как сейчас), тени — `range`/`render_power`/цвет из
палитры, непрозрачность бара 85 → 78, стекло виджетов — из `Theme.qml` (альфа 0.60–0.65,
рамка 0.18–0.20).

Замер (§12.1) определит итоговые `size/passes/vibrancy`: берём самый «стеклянный» набор,
который держит планку FPS на 1920×1080.

## 7. Единая палитра

`theme/palette.toml` — единственный источник. Токены: полная палитра Mocha
(`base`, `mantle`, `crust`, `surface0..2`, `overlay0/1`, `subtext0/1`, `text`, `lavender`,
`blue`, `sapphire`, `sky`, `teal`, `green`, `yellow`, `peach`, `maroon`, `red`, `mauve`,
`pink`, `flamingo`, `rosewater`), шрифты (`font-ui`, `font-mono`, `font-terminal`, размеры),
геометрия (`margin`, `radius`, высоты виджетов).

`theme/render.py` пишет:

| Файл | Способ |
|---|---|
| `~/.config/kitty/theme.conf` | целиком (подключается из `kitty.conf` строкой `include`) |
| `~/.config/wofi/style.css` | блок цветов между маркерами |
| `~/.config/btop/btop.conf` + `~/.config/btop/themes/catppuccin-mocha.theme` | строка темы + файл целиком |
| `~/.config/cava/config` | блок цветов между маркерами |
| `~/.config/starship.toml` | секция `[palettes.mocha]`; сами модули переписываются на именованные цвета |
| `~/.config/fastfetch/config.jsonc` | целиком из шаблона `theme/templates/fastfetch.jsonc.in` |
| `~/.config/gtk-3.0/settings.ini`, `~/.config/gtk-4.0/settings.ini` | блок между маркерами |
| `~/.config/wayle/config.toml` | блок `[styling.palette]` и `font-*` между маркерами |
| `quickshell/widgets/Theme.qml` | блок палитры между маркерами |
| `~/.config/hypr/hyprland.lua` | блок цветов между маркерами (D10) |
| `gsettings` (тема GTK, иконки, курсор, шрифт) | команды `gsettings set` |

`theme/check.sh` — сторож дрейфа: ищет в перечисленных файлах hex-цвета вне палитры и
падение на Tokyo Night (`7aa2f7`, `bb9af7`, `1a1b26`, `24283b`, `1f2335`, `394b70`,
`565f89`, `414868`, `c0caf5`, `e0af68`, `f7768e`). Запускается в `install.sh` и в проверке.

Приложения: GTK3/GTK4 — `catppuccin-mocha-mauve-standard+default` (тема уже установлена,
надо довести до фактического применения), иконки — `Papirus-Dark`, курсор —
`catppuccin-mocha-mauve-cursors` (в Hyprland уже прописан в `hl.env`), шрифт интерфейса —
`JetBrains Mono 11`, терминал — `CozetteVector 13` (как сейчас), бар и виджеты —
`JetBrains Mono` / `JetBrainsMono Nerd Font`.

## 8. Бар Wayle

Сохраняется как бар. Правки:

- палитра и шрифты — из общей палитры (D3);
- блюр за баром включается, `background-opacity` 85 → 78 (D6);
- геометрия согласуется с виджетами: `inset-edge` 0.5 em (8 px), `inset-ends` 0.75 em (12 px),
  `rounding = "lg"`, `scale` и `rounding` для дропдаунов — как у бара;
- раскладка блоков не меняется (слева — рабочие столы и заголовок, по центру — часы и трей,
  справа — группы индикаторов, каждый блок со своим скруглением, зазоров внутри нет);
- добавляется иконки приложений в воркспейсах (`app-icons-show`, дедупликация) — включается
  одним ключом, если понравится на скриншоте;
- уведомления: модуль `notifications` встаёт в правую группу, попапы — `top-right`,
  `popup-duration` 5000, `popup-shadow`, `popup-urgency-bar`, `popup-margin-x/y` 8,
  блок-лист `["*Telegram*"]` (перенос правила `invisible` из mako);
- OSD: `[osd] enabled = true`, позиция `bottom`, `margin` 150, `border`, палитра бара;
- медиа-клавиши (D7):

```lua
hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd("wayle audio output-volume +5"), { locked = true, repeating = true })
hl.bind("XF86AudioLowerVolume", hl.dsp.exec_cmd("wayle audio output-volume -5"), { locked = true, repeating = true })
hl.bind("XF86AudioMute",        hl.dsp.exec_cmd("wayle audio output-mute"),      { locked = true })
hl.bind("XF86AudioMicMute",     hl.dsp.exec_cmd("wayle audio input-mute"),       { locked = true })
hl.bind("XF86MonBrightnessUp",  hl.dsp.exec_cmd("brightnessctl set 5%+"),           { locked = true, repeating = true })
hl.bind("XF86MonBrightnessDown",hl.dsp.exec_cmd("brightnessctl set 5%-"),           { locked = true, repeating = true })
hl.bind("XF86AudioNext",        hl.dsp.exec_cmd("wayle media next"),      { locked = true })
hl.bind("XF86AudioPrev",        hl.dsp.exec_cmd("wayle media previous"),  { locked = true })
hl.bind("XF86AudioPlay",        hl.dsp.exec_cmd("wayle media play-pause"), { locked = true })
hl.bind("XF86AudioPause",       hl.dsp.exec_cmd("wayle media play-pause"), { locked = true })
```

Синтаксис сверен по `wayle --help` (§15): громкость принимает абсолютное значение 0–100 или
относительное `+5`/`-10` (без знака процента), mute — команда без аргументов (переключает),
`wayle media play-pause` принимает необязательный идентификатор плеера.
`playerctl` и `swayosd-client` остаются установленными: откат — вернуть строки привязок.

## 9. Виджеты и композиция стола

Все три виджета берут токены из `Theme.qml` (палитра рендерится, геометрия — руками в файле):

| Токен | Значение |
|---|---|
| `glass` | `rgba(24, 24, 37, 0.62)` |
| `glassEdge` | `rgba(205, 214, 244, 0.20)` |
| `radius` | 16 |
| `margin` | 16 (от краёв экрана) |
| высоты | док 68, эквалайзер 68 (было 64), карточка 96 |

Сцена: низ всех трёх на линии `y = 1080 − 16`; карточка слева (`x = 16`), док по центру,
эквалайзер справа (`x = 1920 − 16 − ширина`). По X геометрия уже такая — выравнивается
низ и высота.

Жизнь в сцене:

- **Карточка плеера:** появление и уход с плавным смещением и прозрачностью (сейчас рывок);
  клик по обложке поднимает окно играющего плеера; заглушка обложки — аккуратная иконка
  из палитры; длинные названия по-прежнему обрезаются.
- **Док:** подъём иконки под курсором, точка у запущенного приложения, всплывающая подпись;
  иконки — из `Papirus-Dark`; клик по запущенному приложению поднимает окно (как сейчас).
- **Эквалайзер:** плавная интерполяция столбиков между кадрами, градиент mauve → blue,
  в тишине — приглушённая базовая линия вместо «выключенного» вида.

Поведение карточки при отсутствии звука остаётся принятым ранее: нет настоящего
воспроизведения — нет карточки (залипший MPRIS без аудиопотока игнорируется).

## 10. Локскрин и лаунчер

**hyprlock:** фон — тёмный вариант тех же обоев (`--lock`), палитра из общей, композиция:
крупное время, дата, приветствие пользователя, поле ввода с акцентом mauve, размытие фона
согласовано со стеклом стола. Поле ввода и подписи — те же шрифты и скругления.

**wofi:** остаётся лаунчером, доводится в общее стекло — скругление 16, размытая подложка
(правило слоя уже есть), иконки `Papirus-Dark`, фокус-подсветка акцентом, тот же шрифт.
Меню истории буфера (`SUPER+V`) уже использует wofi — стиль подхватится автоматически.

## 12. Проверка

### 12.1 Стекло и FPS (замер)

1. Включить оверлей FPS: `hyprctl keyword debug:overlay true`.
2. Нагрузка: полноэкранный `kitty` с `cava` (непрерывное движение под блюром) — худший
   честный случай для композитора.
3. Снять 5 кадров `grim` с интервалом 2 с, прочитать FPS с оверлея.
4. Прогнать наборы `size/passes`: 4/1 (текущий), 6/2, 8/3. Записать таблицу «набор → FPS».
5. Выбрать самый тяжёлый набор, который держит ≥ 55 FPS; если 6/2 не держит — 4/2 с
   `vibrancy`, и это тоже результат, который идёт в отчёт.

Отдельно: контраст структуры обоев в полосе y 880–1080 против центра (нормировка контраста,
как в прошлой проверке блюра) — доказательство, что стеклу есть что размывать.

### 12.2 Приёмка по поверхностям

| Что | Как проверяется |
|---|---|
| Обои | 4 варианта сгенерированы, открываются, низ не пустой; `--lock` даёт тёмный вариант |
| Бар | Скриншот над подробными обоями: текст читается, стекло видно; `wayle panel restart` без ошибок |
| Дропдауны | Громкость, сеть, Bluetooth, календарь, батарея, питание — открываются, закрываются по Esc |
| Уведомления | `notify-send` обычное/критическое/с иконкой; DND по `wayle notify dnd`; блок-лист Telegram |
| OSD | `wayle audio output-volume +5%` — OSD появляется в палитре; поведение при смене яркости — отдельно, с честным результатом |
| Виджеты | Три поверхности подняты, низ на одной линии; карточка появляется при звуке и уходит без него |
| Локскрин | Запуск hyprlock и снимок `grim` (или, если мешает, снимок по просьбе пользователя), сверить фон и палитру |
| GTK | Nautilus: тема, иконки, курсор, шрифт — из палитры |
| Палитра | `theme/check.sh` — чисто; `hyprctl configerrors` — пусто |
| Медиа-клавиши | Привязки видны в `hyprctl binds`; команды из привязок выполняются вручную (нажатие клавиши проверяет пользователь — инъекции ввода у агента нет) |
| Память | RSS Quickshell < 250 МБ (прежний бюджет), Wayle — без регрессии |

Скриншоты складываются в `/tmp/opencode/rice-preview/` и показываются пользователю:
пустой стол (все три виджета, для этого на время включается тихий звук), бар, лаунчер,
уведомление с OSD, локскрин, GTK-приложение, терминал с fastfetch.

## 13. Этапы

**Этап 1 — палитра и обои.** `theme/palette.toml`, `render.py`, `check.sh`; новый генератор
обоев; синхронный локскрин; вычистка Tokyo Night; gsettings. Критерий: все конфиги из
палитры, чекер чист, обои со структурой.

**Этап 2 — стекло.** Значения блюра по замеру, тени, непрозрачности, блюр за баром; правила
слоёв; критерий — таблица FPS и скриншот читаемого бара.

**Этап 3 — обвязка Wayle.** Уведомления и OSD внутрь Wayle, вывод mako и swayosd из
автозапуска, медиа-клавиши, полировка бара. Критерий — уведомления, DND, OSD и медиа-команды
работают; откат одной строкой.

**Этап 4 — сцена и мелочи.** Выравнивание виджетов, жизнь в доке/карточке/эквалайзере,
локскрин, wofi, btop/cava/fastfetch/starship, анимации, хоткей обоев. Критерий — скриншоты
всех поверхностей без замечаний.

**Этап 5 — упаковка.** `install.sh`/`uninstall.sh` с нуля, README, финальная пачка
скриншотов, чистка временного.

Каждый этап: бэкапы → применение → проверка (§12) → коммит в `~/rice`.

## 14. Риски и открытые вопросы

| Риск | Влияние | Смягчение |
|---|---|---|
| Блюр на UHD 620 не держит планку | Просадка FPS, «мыло» | Замер на трёх наборах; при провале — 4/2 с вибрацией, результат в отчёт; блюр за баром отключается одной строкой |
| Wayle 0.7.0 как сервер уведомлений | Потеря уведомлений | Пакеты и конфиги mako/swayosd остаются, откат строкой; проверка живыми уведомлениями, DND и кликом |
| OSD не реагирует на яркость из `brightnessctl` | Нет индикатора яркости | Проверяется отдельно; если не реагирует — либо `swayosd` возвращается только для яркости, либо привязка идёт через Wayle, либо честно документируется отсутствие OSD на яркость |
| Точный синтаксис `wayle audio output-volume` | Привязки не работают | Сверено до правки (§15): относительное значение `+5`/`-10`, mute без аргументов, медиа-команды принимают необязательный id. Остаётся проверить, что команды видны в `hyprctl binds` и работают вручную |
| Цветовой блок в `hyprland.lua` (D10) | Сломанный конфиг композитора | Маркеры + `hyprctl configerrors` + скриншот границ; при сбое — откат блока, цвета остаются написанными руками, соответствие палитре проверяет `check.sh` |
| Разреженность Wayle-темы | Часть элементов остаётся дефолтной | `styles/index.scss` доступен для точечных переопределений |
| Пользователь активно работает за машиной | Снимки перекрыты окнами, анимации мешают | Геометрия проверяется через `hyprctl layers`, снимки — по согласованию, нагрузочные прогоны короткие |

**Открытых вопросов нет.** Всё, что требует решения, решено в §4; всё, что требует
проверки, вынесено в §12 с честным результатом вместо обещания.

## 15. Проверенные факты

Сверено на этой машине (версии, файлы, вывод команд), а не по памяти:

- Hyprland 0.56.2: ключи `decoration:blur:{size,passes,noise,contrast,brightness,vibrancy,vibrancy_darkness,popups,special,new_optimizations,xray,ignore_opacity,input_methods}` существуют (`hyprctl getoption`).
- Текущее значение: `size 4`, `passes 1`, `noise 0`, `vibrancy 0`, `brightness 0.9`, `popups true`.
- Wayle 0.7.0: `[styling]` принимает `theme-provider = wayle|matugen|wallust|pywal`, `scale`, `rounding`, `theming-monitor`; палитра — `[styling.palette]{bg,surface,elevated,fg,fg-muted,primary,red,yellow,green,blue}`.
- Wayle: модуль `notifications` (попапы, `popup-*`, `blocklist`, `icon-source`, DND по правому клику), `[osd]{enabled,position,duration,margin,border,layer}`, `[wallpaper]{engine-enabled}`.
- Wayle CLI: `audio {output-volume,output-mute,input-volume,input-mute,sinks,sources,status}`, `media {list,play-pause,next,previous,shuffle,loop,active,info}`, `notify {list,dismiss,dismiss-all,dnd,status}`, `wallpaper {set,cycle,stop,next,previous,info,theming-monitor}`, `panel {start,restart}`.
- Синтаксис Wayle сверен по `--help`: `wayle audio output-volume [LEVEL]` — абсолютное 0–100 или относительное `+5`/`-10` (знак процента не принимается, единица — проценты); `wayle audio output-mute` и `wayle audio input-mute` — без аргументов, переключают; `wayle media play-pause [PLAYER_ID]` — идентификатор необязателен (номер или часть имени); `wayle notify dnd` — без аргументов.
- `brightnessctl` 0.5 установлен — привязки яркости пойдут через него.
- Уведомления сейчас держит mako (`org.freedesktop.Notifications` → pid 15828); mako и swayosd-server запущены из `hyprland.lua`.
- Шрифты: `CozetteVector`, `JetBrains Mono`, `Noto Sans`, `Cantarell`, `Adwaita Sans` (164 файла с JetBrains/Nerd).
- Установлено и не используется: тема `~/.themes/catppuccin-mocha-mauve-standard+default`, курсор `~/.local/share/icons/catppuccin-mocha-mauve-cursors`, иконки `Papirus`/`Papirus-Dark`.
- `gsettings` (интерфейс): тема `Tokyonight-Dark`, иконки `Adwaita`, курсор `Adwaita`, шрифт `Adwaita Sans 11` — расходится с `~/.config/gtk-3.0/settings.ini`, где уже прописан Catppuccin.
- Следы Tokyo Night: `~/.config/starship.toml`, `~/.config/fastfetch/config.jsonc`.
- `hl.env` в `hyprland.lua` уже задаёт `XCURSOR_THEME`/`HYPRCURSOR_THEME` = `catppuccin-mocha-mauve-cursors`, размер 24.
- Монитор: eDP-1 1920×1080@60, HDR нет. Масштаб 1.
- Хоткеи скриншотов и буфера обмена уже есть (`SUPER+A`, `SUPER+SHIFT+A`, `SUPER+V`, `Print`).
- `hyprlock` этой версии не умеет снимок сам (`--immediate-render`, `--grace` есть, флага снимка нет) — снимок локскрина делается через `grim` при заблокированном экране.

- Инъекции ввода у агента нет (нет `ydotool`-сокета, `wlrctl`, `/dev/uinput` недоступен) — нажатия клавиш проверяет пользователь, команды из привязок агент проверяет вручную.
